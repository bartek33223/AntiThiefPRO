# AntiThiefPRO

Free Android motion-alarm starter app.

## Build
Push to `main` or run the **Build AntiThiefPRO APK** workflow from the Actions tab. Download the `AntiThiefPRO-debug` artifact from a successful run.

## Features in this version
- Motion-triggered sound and vibration alarm while the app is open.
- PIN-protected disarming and PIN change.
- No account, ads, analytics, or network permission.

## Important limitations
This first version does not monitor movement in the background or after the app is closed. The initial PIN is `1234`; change it before using the alarm. This is a debug APK for testing, not a Play Store release.
